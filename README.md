# Movie Ticket Booking Management

## Project Overview

Movie Ticket Booking Management is a Pega App Studio application designed
to manage movie ticket booking requests from data capture through booking
confirmation.

## Pega Application

Application Name: Fraud Investigation

Case Type: Movie Ticket Request

Platform: Pega App Studio

## Main Features

- Enter Movie Details
- Select Show Type
- Select Show Date and Time
- Enter Number of Tickets
- Validate Booking Details
- Check Show Availability
- Calculate Booking Cost
- Allocate Seats
- Generate Ticket ID
- Customer Confirmation
- Update Booking Status
- Send Booking Confirmation
- Resolve Booking Case

## Workflow

Data Capture
→ Show Lookup
→ Availability Check
→ Cost Calculation
→ Seat Allocation
→ Customer Confirmation
→ Booking Confirmation
→ Case Resolution
